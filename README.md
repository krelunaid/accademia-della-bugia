# Accademia della Bugia

App dell’Accademia della Bugia (Le Piastre, Pistoia): bacheca, sfide, lotteria, almanacco e redazione.

Sulla Home del telefono si chiama **La Bugia**, con il Bugiardino d’oro.

## Avvio

```bash
npm install
npm run dev
```

Apri `http://localhost:8080`.

- **Redazione:** entra e usa il codice `LEPIASTRE1966` per pubblicare annunci e sfide.
- **Installazione:** da Safari o Chrome, Aggiungi alla schermata Home.

## Stack

TanStack Start, Better Auth, PGLite, Tailwind.
